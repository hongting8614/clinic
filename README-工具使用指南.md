## 🎯 常见问题解决流程

### 问题1：文件下载失败

**错误信息：**
```
downloadFile:fail Error: tunneling socket could not be established
cause=connect ECONNREFUSED 127.0.0.1:7890
```

**解决方案：**
1. 双击运行 `1-修复代理并启动.bat`
2. 或者手动关闭代理软件
3. 重新测试导出功能

**如果还是失败：**
- 使用真机测试（参考 `真机测试指南.md`）
- 重启电脑后再试

---

### 问题2：导出文件中出现 [object Object]

**解决方案：**
1. 双击运行 `2-修复导出问题.bat`
2. 打开微信开发者工具
3. 右键点击 `cloudfunctions/reports` 文件夹
4. 选择"上传并部署：云端安装依赖"
5. 等待部署完成
6. 重新测试导出功能

**手动修复：**
- 参考 `修复指南.md` 中的详细步骤

---

### 问题3：表头显示多行

**解决方案：**
1. 双击运行 `2-修复导出问题.bat`
2. 重新部署云函数
3. 测试导出

**说明：**
- 脚本会自动将表头的 `wrapText: true` 改为 `wrapText: false`
- 确保表头只显示一行

### 微信开发者工具路径
默认路径：
```
C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat

如果您的安装路径不同，请修改 `启动工具.ps1` 中的 `$wechatTool` 变量。

```
D:\AK-PMS\unpackage\dist\dev\mp-weixin

## 🔍 故障排查

### 工具无法运行

**可能原因：**
1. PowerShell 执行策略限制
2. 路径配置错误
3. 权限不足

**解决方案：**
```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后重新运行工具
```

---

### 修复后仍有问题

**检查清单：**
- [ ] 是否重新部署了云函数
- [ ] 是否清除了缓存
- [ ] 是否重新编译了项目
- [ ] 是否选择了有数据的日期范围

**获取帮助：**
1. 查看控制台日志
2. 查看云函数日志
3. 截图错误信息
4. 参考相关文档
