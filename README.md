## 🎊 项目概述

AK-PMS 是一套专为北京欢乐谷医务室打造的专业药材管理系统，支持多园区（陆园、水园、园区项目）的药材入库、出库、库存管理和日常消耗记录。

### 核心特性
- ✅ **批次级库存管理** - 精确到批次，支持FIFO先进先出
- ✅ **多园区支持** - 陆园、水园、园区项目独立管理
- ✅ **扫码快速录入** - 条形码扫描，自动填充数据
- ✅ **智能预警** - 低库存预警、近效期预警
- ✅ **电子签名** - 双人复核，操作留痕
- ✅ **实时统计** - 数据可视化，趋势分析

## ✨ 主要功能

### 1. 药材入库管理 ✅
- 扫码/手动添加药材
- 批次信息管理（批号、生产日期、有效期）
- 双人复核机制（操作员+复核员电子签名）
- 草稿保存功能
- 高值药材/急救药材标记

### 2. 园区领用管理（出库）✅
- 支持陆园、水园、园区项目三园区
- 智能批次选择（FIFO先进先出）
- 库存实时验证
- 高值药材金额提示
- 近效期药材警示
- 双人复核机制

### 3. 门诊登记管理 ✅
- 患者信息登记（姓名、性别、年龄、身份）
- 主诉、诊断、处置记录
- 用药记录（最小单位：片、粒、袋、支）
- 出诊信息记录
- 医生签名确认
- 门诊日报导出

### 4. 门诊日消耗记录 ✅
- 按园区记录消耗（陆园/水园）
- 按日期记录
- 扫码添加药材
- 自动加载园区批次
- 库存验证
- 自动扣减库存

### 5. 库存管理 ✅
- 实时库存查询
- 批次详情管理
- 低库存预警（红色标识）
- 近效期预警（黄色标识，6个月内）
- 过期药材标识（黑色）
- 按园区分库存
- 高值药材标识

### 6. 药材档案管理 ✅
- 药材基础信息维护
- **条形码管理**（扫码/手动录入）
- 单位转换设置（包装单位↔最小单位）
- 安全库存设置
- 药材分类管理
- 特殊标记（高值、急救）

### 7. 数据报表 ✅
- 门诊日报
- 入库报表
- 出库报表
- 库存报表
- 消耗统计
- Excel格式导出（格式优化）
- 按时间段和园区筛选

### 8. 系统设置 ✅
- 用户管理
- 角色权限配置（管理员、项目经理、医生）
- 密码修改
- 操作日志
- 园区管理
