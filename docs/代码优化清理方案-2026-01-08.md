## 二、清理建议

### 2.1 立即删除（确定未使用）

#### 文件清理列表

```
pages-sub/report/weekly.vue
pages-sub/report/monthly.vue
```

#### pages.json 配置清理

```json

    "navigationBarTitleText": "周统计"
  }
},
{
  "path": "monthly",
  "style": {
    "navigationBarTitleText": "月统计"
  }
}
```

### 2.2 需要确认后删除

#### 门诊统计分析页面

**文件**: `pages-sub/report/clinic-analysis.vue`

**决策依据**：
- ✅ 保留：如果需要门诊数据分析功能（疾病统计、用药分析）
- ❌ 删除：如果确定不需要此功能，可以删除

**如果删除，需要同时删除 pages.json 中的配置**：
```json
{
  "path": "clinic-analysis",
  "style": {
    "navigationBarTitleText": "门诊统计分析"
  }
}
```

#### 未使用的业务模块

**需要确认的模块**：
1. 调拨管理 (transfer)
2. 门诊日消耗 (consume)
3. 请领单 (requisition)
4. 盘点管理 (inventory)
5. 报损管理 (damage)
6. 退货管理 (return)

**确认方式**：
1. 检查是否在任何页面中有跳转链接
2. 询问业务方是否需要这些功能
3. 检查云函数中是否有相关数据操作

**如果确认不需要，删除步骤**：
1. 删除对应的文件夹
2. 从 pages.json 的 subPackages 中删除对应配置
3. 检查并删除相关的云函数
