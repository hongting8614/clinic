## 🐛 问题根源分析

### 问题1：字段名不一致 ⭐⭐⭐⭐⭐

**现象：** 药材档案中有条形码，但扫码查询失败

**根本原因：** 数据库中存在两种字段名

```javascript
// 药材档案表(drugs)中可能存在的字段名：
{
  "barcode": "6901028075862",  // 小写（新版）
  "barCode": "6901028075862"   // 驼峰（旧版）
}
```

**当前查询逻辑：**
```javascript
// ✅ 云函数已兼容两种字段名
const res = await db.collection('drugs')
  .where(_.or([
    { barcode: barcode },      // 小写字段
    { barCode: barcode }       // 驼峰字段
  ]))
  .get()
```

**但是：** 前端保存时可能只保存了一种字段名！

---

### 问题2：条形码格式不一致

**可能的问题：**
1. 扫码结果包含空格、换行符
2. 数据库中的条形码包含特殊字符
3. 大小写不一致

**当前处理：**
```javascript
// ✅ 前端已做清洗
let cleanBarcode = scanRes.result
  .trim()                    // 去除首尾空格
  .replace(/\s/g, '')        // 去除所有空格
  .replace(/[\r\n]/g, '')    // 去除换行符
```

**但是：** 数据库中的条形码可能没有清洗！

---

### 问题3：数据库索引缺失

**影响：** 查询速度慢，可能超时

**当前状态：** 未知是否创建索引

**建议：** 为 `barcode` 和 `barCode` 字段创建索引

---

### 问题4：错误提示不够详细

**当前提示：**
```javascript
uni.showToast({
  title: '扫码失败，请重试',
  icon: 'none'
})
```

**问题：** 用户不知道为什么失败，无法排查问题

#### 1.1 创建数据迁移脚本

```javascript
// scripts/migrate-barcode-field.js
const cloud = require('wx-server-sdk')

cloud.init({ env: 'your-env-id' })
const db = cloud.database()

async function migrateBarcode() {
  console.log('开始迁移条形码字段...')
  
  // 查询所有有 barCode 字段的药品
  const res = await db.collection('drugs')
    .where({
      barCode: db.command.exists(true)
    })
    .get()
  
  console.log(`找到 ${res.data.length} 条需要迁移的记录`)
  
  let successCount = 0
  let errorCount = 0
  
  for (const drug of res.data) {
    try {
      // 如果没有 barcode 字段，从 barCode 复制
      if (!drug.barcode && drug.barCode) {
        await db.collection('drugs').doc(drug._id).update({
          data: {
            barcode: drug.barCode  // 复制到小写字段
          }
        })
        successCount++
        console.log(`✅ ${drug.name}: ${drug.barCode}`)
      }
    } catch (err) {
      errorCount++
      console.error(`❌ ${drug.name}: ${err.message}`)
    }
  }
  
  console.log('========================================')
  console.log(`迁移完成！`)
  console.log(`成功: ${successCount} 条`)
  console.log(`失败: ${errorCount} 条`)
  console.log('========================================')
}

migrateBarcode()
```

### 方案4：条形码清洗工具（数据修复）⭐⭐⭐

**目标：** 清洗数据库中的条形码，去除空格、特殊字符

```javascript
// scripts/clean-barcodes.js
const cloud = require('wx-server-sdk')

cloud.init({ env: 'your-env-id' })
const db = cloud.database()

async function cleanBarcodes() {
  console.log('开始清洗条形码...')
  
  // 查询所有有条形码的药品
  const res = await db.collection('drugs')
    .where({
      barcode: db.command.exists(true)
    })
    .get()
  
  console.log(`找到 ${res.data.length} 条记录`)
  
  let cleanedCount = 0
  
  for (const drug of res.data) {
    const originalBarcode = drug.barcode
    
    // 清洗条形码
    const cleanedBarcode = originalBarcode
      .trim()
      .replace(/\s/g, '')
      .replace(/[\r\n]/g, '')
    
    // 如果清洗后不同，更新数据库
    if (cleanedBarcode !== originalBarcode) {
      await db.collection('drugs').doc(drug._id).update({
        data: {
          barcode: cleanedBarcode
        }
      })
      cleanedCount++
      console.log(`✅ ${drug.name}: "${originalBarcode}" → "${cleanedBarcode}"`)
    }
  }
  
  console.log(`清洗完成！共清洗 ${cleanedCount} 条记录`)
}

cleanBarcodes()
```

## 🎯 总结

### 核心问题
