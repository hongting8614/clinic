### 1. 药材录入方式（三种）

#### 📷 扫码入库
- 调用微信扫码API (`uni.scanCode`)
- 自动查询云数据库中的药材信息
- 支持**连续扫码模式**（自动再次唤起扫码）
- 未找到药材时引导手动录入
- 用户取消扫码不显示错误提示

**实现位置**: `pages-sub/in/add.vue` - `handleScan()` 方法

```javascript
async handleScan() {
  this.scanning = true
  try {
    const res = await uni.scanCode({ onlyFromCamera: true })
    const barcode = res[1].result
    
    // 调用云函数查询药材
    const result = await wx.cloud.callFunction({
      name: 'drugManage',
      data: { action: 'getByBarcode', data: { barcode } }
    })
    
    if (result.result.success && result.result.data) {
      this.addDrugToList(result.result.data, 'scan')
      
      // 连续扫码模式
      if (this.continuousScan) {
        setTimeout(() => this.handleScan(), 500)
      }
    } else {
      // 未找到，引导手动录入
      uni.showModal({
        title: '未找到药材',
        content: '该条码未在系统中找到，是否手动录入？',
        success: (res) => {
          if (res.confirm) this.handleCreateDrug(barcode)
        }
      })
    }
  } catch (err) {
    if (!err.errMsg?.includes('cancel')) {
      uni.showToast({ title: err.errMsg || '扫码失败', icon: 'none' })
    }
  } finally {
    this.scanning = false
  }
}
```

```javascript
  errorMessage = '生产日期不能为空'
```

### 4. 双签名审核流程

#### 流程状态
```
draft (草稿)
  ↓ 保存草稿
draft (草稿)
  ↓ 提交复核 + 操作员签名
pending_review (待复核)
  ↓ 复核通过 + 复核员签名
completed (已完成) + 自动更新库存
  ↓ 或驳回
rejected (已驳回)
```

#### 操作员签名
- **时机**: 点击"提交复核"时
- **组件**: `components/signature/index.vue`
- **存储**: 签名图片上传到云存储，URL保存到 `operatorSign` 字段
- **验证**: 必须签名才能提交


#### 复核员签名
- **时机**: 在详情页点击"通过复核"时
- **组件**: `components/signature/index.vue`

**云函数逻辑** (`cloudfunctions/inRecords/index.js`):
```javascript
async function approve(data, wxContext) {
  const { _id, reviewer, reviewerId, reviewerSign } = data
  
  // 检查记录状态
  const record = await db.collection('in_records').doc(_id).get()
  
  if (record.data.status !== 'pending_review') {
    throw new Error('只能复核待审核的单据')
  }
  
  // 不能自己复核自己的单据
  if (record.data.operatorId === reviewerId) {
    throw new Error('不能自己复核自己的单据')
  }
  
  // 更新状态
  await db.collection('in_records').doc(_id).update({
    data: {
      status: 'completed',
      reviewer,
      reviewerId,
      reviewerSign,
      reviewerSignTime: new Date(),
      completeTime: new Date()
    }
  })
  
  // 自动更新库存
  for (const item of record.data.items) {
    await updateStock({ ...item, action: 'in' })
  }
  
  return { success: true, message: '复核通过，库存已更新' }
}
```

### 5. 库存自动更新

#### 更新时机
- 复核通过（`status: completed`）时自动触发
- 由云函数 `inRecords/approve` 调用 `updateStock`

#### 更新逻辑
```javascript
async function updateStock(data) {
  const { drugId, batch, location, quantity, action } = data
  
  // 查找批次
  const stockQuery = await db.collection('stock').where({
    drugId,
    batch,
    location
  }).get()
  
  if (stockQuery.data.length > 0) {
    // 已存在，累加数量
    const stock = stockQuery.data[0]
    const newQuantity = action === 'in' 
      ? stock.quantity + quantity 
      : stock.quantity - quantity
    
    await db.collection('stock').doc(stock._id).update({
      data: { quantity: newQuantity, updateTime: new Date() }
    })
  } else {
    // 不存在，新增库存记录
    await db.collection('stock').add({
      data: {
        drugId,
        drugName,
        batch,
        quantity,
        expireDate,
        status: calculateStatus(expireDate), // 'normal', 'near_expire', 'expired'
        createTime: new Date()
      }
    })
  }
}
```

#### 效期状态计算
```javascript
const daysToExpire = Math.floor((new Date(expireDate) - new Date()) / (1000 * 60 * 60 * 24))

let status = 'normal'
if (daysToExpire < 0) {
  status = 'expired'
} else if (daysToExpire <= 90) {
  status = 'near_expire'
}
```

## 📝 使用说明

### 操作员流程

1. 进入"入库管理"
2. 点击"+"新建入库单
3. 填写供应商（选填）
4. 添加药材（扫码/选择/新建）
5. 填写批次信息（批号、生产日期、有效期、数量、单价）
6. 手写签名
7. 提交复核

### 复核员流程

1. 进入"入库管理"
2. 点击"待复核"标签
3. 选择待复核单据
4. 检查药材明细
5. 手写签名
6. 点击"通过复核"（或"驳回"）

### 草稿管理

- 随时保存草稿（不需要签名）
- 可编辑草稿
- 可删除草稿

### 驳回处理

- 查看驳回原因
- 重新编辑
- 重新提交

## 🔒 权限控制

| 角色 | 创建 | 编辑草稿 | 删除草稿 | 提交复核 | 复核通过/驳回 |
|------|------|---------|---------|---------|--------------|
| 操作员 | ✅ | ✅（自己的） | ✅（自己的） | ✅ | ❌ |
| 复核员 | ✅ | ✅（自己的） | ✅（自己的） | ✅ | ✅（别人的） |

**规则**:
- ✅ 只能编辑/删除自己创建的草稿或被驳回的单据
- ✅ 不能复核自己创建的单据
- ✅ 只有待复核状态的单据才能被复核

## ⚡ 性能优化

1. **组件化**: 工具栏和表格独立组件，便于复用和维护
2. **v-model双向绑定**: 减少事件传递，简化数据流
3. **按需验证**: 输入框失焦时验证，避免频繁验证
4. **分页加载**: 列表页分页加载，避免一次加载大量数据
5. **事件清理**: `onUnload` 时移除全局事件监听，避免内存泄漏
