### 1. ✅ 档案完整度显示功能

#### 功能描述
在搜索结果中实时显示每个药品档案的完整度百分比，帮助用户快速识别档案质量。

#### 实现细节

**新增方法：**

```javascript
// 计算档案完整度
calculateCompleteness(drug) {
    const fields = [
        drug.name,           // 名称
        drug.specification,  // 规格
        drug.unit,          // 单位
        drug.manufacturer,  // 生产厂家
        drug.barcode,       // 条形码
        drug.approvalNumber,// 批准文号
        drug.category,      // 分类
        drug.image          // 图片
    ]
    
    const filledCount = fields.filter(field => field && field.trim()).length
    const percentage = Math.round((filledCount / fields.length) * 100)
    
    return {
        percentage,
        filledCount,
        totalCount: fields.length,
        isComplete: percentage === 100,
        missingFields: this.getMissingFields(drug)
    }
}

// 获取缺失字段
getMissingFields(drug) {
    const fieldMap = {
        name: '名称',
        specification: '规格',
        unit: '单位',
        manufacturer: '生产厂家',
        barcode: '条形码',
        approvalNumber: '批准文号',
        category: '分类',
        image: '图片'
    }
    
    const missing = []
    for (const [key, label] of Object.entries(fieldMap)) {
        if (!drug[key] || !drug[key].trim()) {
            missing.push(label)
        }
    }
    
    return missing
}
```

**UI展示：**

- **100%** - 绿色渐变徽章 🟢 档案完整
- **75-99%** - 蓝色渐变徽章 🔵 档案良好
- **50-74%** - 橙色渐变徽章 🟠 档案一般
- **<50%** - 红色渐变徽章 🔴 档案不完整

**缺失字段提示：**
- 在药品规格下方显示："缺少：条形码、批准文号、分类"
- 橙色文字，醒目提示

### 2. ✅ 完善档案入口

#### 功能描述
为档案不完整的药品提供快捷编辑入口，用户可直接跳转到编辑页面完善信息。

#### 实现细节

**新增方法：**

```javascript
// 完善药品档案
improveDrugProfile(drug) {
    uni.showModal({
        title: '完善档案',
        content: `档案完整度：${drug.completeness.percentage}%\n缺少：${drug.completeness.missingFields.join('、')}\n\n是否前往完善？`,
        confirmText: '去完善',
        cancelText: '稍后',
        success: (res) => {
            if (res.confirm) {
                // 跳转到药品编辑页面
                uni.navigateTo({
                    url: `/pages-sub/drugs/edit?id=${drug._id}&from=inbound`
                })
            }
        }
    })
}
```

#### 3.2 厂家智能提示

**功能描述：**
输入厂家名称时，自动从现有药品档案中查询匹配的厂家，提供智能建议。

**实现细节：**

```javascript
// 厂家输入时智能提示
async onManufacturerInput(e) {
    const keyword = e.detail.value.trim()
    
    if (!keyword || keyword.length < 2) {
        this.manufacturerSuggestions = []
        this.showManufacturerSuggestions = false
        return
    }
    
    try {
        // 从现有药品中查询厂家
        const db = wx.cloud.database()
        const result = await db.collection('drugs')
            .where({
                manufacturer: db.RegExp({
                    regexp: keyword,
                    options: 'i'
                })
            })
            .field({ manufacturer: true })
            .limit(20)
            .get()
        
        if (result.data.length > 0) {
            // 去重
            const manufacturers = [...new Set(result.data.map(item => item.manufacturer).filter(m => m))]
            this.manufacturerSuggestions = manufacturers.slice(0, 5)
            this.showManufacturerSuggestions = true
        }
    } catch (err) {
        console.error('查询厂家失败:', err)
    }
}

// 选择厂家建议
selectManufacturer(manufacturer) {
    this.newDrug.manufacturer = manufacturer
    this.showManufacturerSuggestions = false
    this.manufacturerSuggestions = []
}
```

**触发条件：**
- 输入≥2个字符时开始查询
- 实时显示最多5条建议
- 点击建议自动填充

**UI设计：**

```

  ┌───────────────────────────┐
  │ 云南白药集团股份有限公司   │
  │ 云南白药集团中药资源公司   │
  │ 云南白药集团文山七花公司   │
```

**优势：**
- 📝 减少输入：避免重复输入长厂家名称

```javascript
        .get()
    
    if (result.data.length > 0) {

        this.manufacturerSuggestions = manufacturers.slice(0, 5)
```
