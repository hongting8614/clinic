# 药材单位转换逻辑说明文档

## 📋 业务需求

### 核心需求
- **入库**：以包装单位（盒、瓶等）入库到药库
- **出库**：以包装单位（盒、瓶等）从药库出库到园区
- **园区库存**：自动转换为最小单位（片、粒等）存储和显示
- **门诊用药**：使用最小单位（片、粒等）登记和扣减

---

## 🔧 技术实现

### 1. 规格解析工具 (`utils/unitConverter.js`)

#### 支持的规格格式

| 格式类型 | 示例 | 解析结果 |
|---------|------|---------|
| **标准格式** | `0.25g×24粒/盒` | conversionRate: 24<br>minUnit: 粒<br>packUnit: 盒 |
| **简化格式** | `24粒/盒` | conversionRate: 24<br>minUnit: 粒<br>packUnit: 盒 |
| **单一包装** | `20g/支` | conversionRate: 1<br>minUnit: 支<br>packUnit: 支 |
| **纯数量** | `100片` | conversionRate: 100<br>minUnit: 片<br>packUnit: 盒 |

#### 核心方法

```javascript
// 1. 解析规格
const specInfo = UnitConverter.parseSpecification('0.25g×24粒/盒')
// 返回：
// {
//   dosage: 0.25,
//   dosageUnit: 'g',
//   conversionRate: 24,  // 转换率
//   minUnit: '粒',       // 最小单位
//   packUnit: '盒',      // 包装单位
//   pattern: 'standard'
// }

// 2. 包装 → 最小单位
const minQuantity = UnitConverter.packToMin(2, 24)  // 2盒 × 24 = 48粒

// 3. 最小 → 包装单位
const packQuantity = UnitConverter.minToPack(48, 24)  // 48粒 ÷ 24 = 2盒

// 4. 格式化显示
const display = UnitConverter.formatStockWithConversion(54, specInfo)
// 返回："54粒 (2盒零6粒)"
```

// cloudfunctions/outRecords/index.js (第 88-120 行)
async function createRecord(data, wxContext) {
  const convertedItems = []
  
  for (const item of items) {
    // 1. 解析规格
    const specInfo = UnitConverter.parseSpecification(item.specification)
    
    // 2. 转换数量（包装→最小）⭐
    const minQuantity = UnitConverter.packToMin(
      item.quantity,              // 2盒
      specInfo.conversionRate     // 24
    )  // = 48粒
    
    // 3. 构建转换后的记录
    convertedItems.push({
      // 药库扣减（包装单位）
      packQuantity: item.quantity,      // 2盒
      packUnit: specInfo.packUnit,      // 盒
      
      // 园区入库（最小单位）⭐
      minQuantity: minQuantity,         // 48粒
      minUnit: specInfo.minUnit,        // 粒
      
      // 规格信息
      specInfo: specInfo,
      conversionRate: specInfo.conversionRate
    })
  }
  
  // 保存出库单
  await db.collection('out_records').add({
    data: {
      items: convertedItems,
      // ...
    }
  })
}

// 完成出库（执行库存变更）
async function complete(data, wxContext) {
  // 1. 扣减药库库存（包装单位）⭐
  await db.collection('stock').doc(stock._id).update({
    data: {
      quantity: _.inc(-item.packQuantity),  // -2盒
    }
  })
  
  // 2. 增加园区库存（最小单位）⭐
  await db.collection('stock').add({
    data: {
      drugId: item.drugId,
      location: record.data.toLocation,  // 陆园
      unit: item.minUnit,                // 粒
      quantity: item.minQuantity,        // 48粒
      specInfo: item.specInfo,
      // ...
    }
  })
}

### 前端组件示例

```vue
<!-- 园区库存显示 -->
<view class="stock-display">
  <text class="main-unit">{{ stock.quantity }}{{ stock.unit }}</text>
  <text class="sub-unit" v-if="stock.specInfo">
    ({{ formatConversion(stock) }})
  </text>
</view>

<script>
export default {
  methods: {
    formatConversion(stock) {
      const { quantity, specInfo } = stock
      const packQty = quantity / specInfo.conversionRate
      const fullPacks = Math.floor(packQty)
      const remainMin = quantity % specInfo.conversionRate
      
      if (fullPacks === 0) {
        return `${packQty.toFixed(2)}${specInfo.packUnit}`
      } else {
        return `${fullPacks}${specInfo.packUnit}零${remainMin}${specInfo.minUnit}`
      }
    }
  }
}
</script>
```

## 🔍 常见问题

### Q1: 为什么药库用包装单位，园区用最小单位？

**A:** 
- **药库**：采购、入库、盘点都是按包装单位（盒、瓶），便于管理
- **园区**：门诊用药是按片、粒发放，使用最小单位更精确

### Q2: 如何处理无法解析的规格？

**A:** 
```javascript
const specInfo = UnitConverter.parseSpecification(spec)
if (!specInfo) {
  // 降级处理：默认转换率为1
  specInfo = {
    conversionRate: 1,
    minUnit: item.unit,
    packUnit: item.unit
  }
}
```

### Q3: 如何处理小数数量？

**A:** 
- **入库**：只允许整数包装（如：100盒）
- **出库**：只允许整数包装（如：2盒）
- **门诊**：允许小数最小单位（如：2.5片）

### Q4: 如何迁移旧数据？

**A:** 
```javascript
// 批量更新库存，添加 specInfo
const stocks = await db.collection('stock').get()
for (const stock of stocks.data) {
  const specInfo = UnitConverter.parseSpecification(stock.specification)
  if (specInfo) {
    await db.collection('stock').doc(stock._id).update({
      data: {
        specInfo: specInfo,
        pricePerMin: UnitConverter.calcMinUnitPrice(stock.price, specInfo.conversionRate)
      }
    })
  }
}
```

## 📝 总结

### 核心原则
1. **药库**：包装单位存储（盒、瓶）
2. **园区**：最小单位存储（片、粒）
3. **出库**：自动转换（包装→最小）
4. **门诊**：最小单位使用（片、粒）

### 优势
- ✅ 符合实际业务流程
- ✅ 数据精确，避免误差
- ✅ 显示直观，易于理解
- ✅ 自动转换，减少人工计算

### 注意事项
- ⚠️ 规格必须标准化（如：0.25g×24粒/盒）
- ⚠️ 转换率必须正确
- ⚠️ 单位必须统一（片、粒、支等）
