# 库存查询系统架构设计文档

## 📋 需求概述

实现支持**总库存、水园、陆园**分库存查询的库存管理系统，满足多园区药品库存管理需求。

## 🔄 数据流设计

### 查询流程

```
用户选择园区 (水园)
    ↓
前端构建查询参数
{
  location: 'water_park',
  stockFilter: 'all',
  expiryFilter: 'all'
}
    ↓
调用云函数 reports.stockReport
    ↓
云函数查询数据库
WHERE location = 'water_park'
    ↓
返回数据
{
  statistics: {
    totalDrugs: 65,
    totalStock: 580,
    lowStockCount: 8,
    expiringCount: 3
  },
  items: [...]
}
    ↓
前端处理数据
- 计算库存状态 (充足/预警/缺货)
- 计算有效期状态 (正常/近效期/已过期)
- 添加园区名称映射
    ↓
渲染UI展示
```

### 统计计算逻辑

```javascript
// 库存状态判断
if (quantity <= 0) {
  status = '缺货'
} else if (quantity <= minStock) {
  status = '预警'
} else {
  status = '充足'
}

// 有效期状态判断
diffDays = (expireDate - today) / 86400000
if (diffDays < 0) {
  status = '已过期'
} else if (diffDays <= 90) {
  status = '近效期'
} else {
  status = '正常'
}
```

## 🔧 核心功能实现

### 1. 园区筛选

```javascript
// 前端过滤逻辑
if (activeLocation === 'all') {
  // 显示所有园区
  list = rows
} else if (activeLocation === 'has_stock') {
  // 只显示有库存的
  list = rows.filter(i => i.quantity > 0)
} else {
  // 按具体园区筛选
  list = rows.filter(i => i.location === activeLocation)
}
```

### 2. 总库存聚合

**场景：** 同一药品在水园和陆园都有库存

```javascript
// 云函数端实现
if (location === 'all') {
  // 按药品名称+规格聚合
  const aggregated = await db.collection('drug_inventory')
    .aggregate()
    .group({
      _id: {
        drugName: '$drugName',
        specification: '$specification'
      },
      totalQuantity: $.sum('$quantity'),
      locations: $.push({
        location: '$location',
        quantity: '$quantity',
        batch: '$batch',
        expireDate: '$expireDate'
      })
    })
    .end()
}
```

### 3. 多维度统计


## 🚀 性能优化

### 1. 数据库优化

- ✅ 添加复合索引 `(location, drugName, expireDate)`
- ✅ 使用聚合管道减少数据传输
- ✅ 分页查询（每页 100 条）

### 2. 前端优化

- ✅ 使用计算属性缓存过滤结果
- ✅ 虚拟滚动（长列表优化）
- ✅ 防抖搜索（300ms）

### 3. 缓存策略

```javascript
// 缓存查询结果 5 分钟
const cacheKey = `stock_${location}_${stockFilter}_${expiryFilter}`
const cached = cache.get(cacheKey)
if (cached && Date.now() - cached.time < 300000) {
  return cached.data
}
```
