# 药材库存模块重构方案

## 📋 现状问题

### 当前架构
```
药材库存
├── 库存查询 (query.vue)
├── 近效期药材 (query.vue?filter=expiring)  ← 功能重复
└── 药材库存报表 (stock.vue)
```

### 存在问题
1. **功能重复**：近效期药材只是库存查询的一个筛选条件，独立成按钮造成冗余
2. **功能分散**：库存查询和库存报表功能重叠，用户不知道该用哪个
3. **缺少整合**：园区维度、批次明细、导出功能分散在不同页面
4. **用户困惑**：三个按钮名称相似，功能边界不清晰

---

## 🎯 重构目标

1. **功能整合**：合并重复功能，减少用户选择成本
2. **职责清晰**：每个入口功能定位明确，互不重叠
3. **体验优化**：减少页面跳转，提升操作效率
4. **扩展性强**：为未来功能扩展预留空间

---

## 🏗️ 新架构设计

### 重构后架构

```
药材库存
├── 📊 库存总览  → 综合查询与统计（主入口）
├── 🏞️ 园区库存  → 园区批次明细管理
└── ⚠️ 预警中心  → 快捷入口（可选）
```

## 📱 详细功能设计

### 1. 📊 库存总览（主入口）

**页面路径：** `/pages-sub/stock/overview`

**功能定位：** 药材库存的综合查询、统计、分析、导出

#### 核心功能

```

│          库存总览                        │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  园区筛选                                │
│  📦 总库存  |  💧 水园  |  🏞️ 陆园        │
├─────────────────────────────────────────┤
│  🔍 搜索药材名称/规格/拼音               │
├─────────────────────────────────────────┤
│  状态筛选                                │
│  全部 | 充足 | 预警 | 缺货               │
├─────────────────────────────────────────┤
│  效期筛选                                │
│  全部 | 近效期 | 已过期                  │
└─────────────────────────────────────────┘

┌──────────────┬──────────────┐
│ 药材种类: 125│ 总库存: 1234 │
├──────────────┼──────────────┤
│ 预警药材: 15 │ 近效期: 8    │
└──────────────┴──────────────┘

┌─────────────────────────────────────────┐
│ 布洛芬缓释胶囊            [水园] #1      │
│ 0.3g*20粒                               │
│ 库存: 50盒  状态: 充足                  │
│ 有效期: 2027-01-06  剩余 362 天         │
└─────────────────────────────────────────┘

[导出Excel] [导出PDF] [查看批次]
```

#### 功能清单

✅ **多维度筛选**
- 园区维度：总库存、水园、陆园
- 库存状态：全部、充足、预警、缺货
- 效期状态：全部、近效期（90天内）、已过期
- 关键词搜索：药材名称、规格、拼音

✅ **统计数据**
- 药材种类数（按筛选条件）
- 总库存数量（只统计quantity>0）
- 预警药材数
- 近效期/已过期批次数

✅ **列表展示**
- 药材卡片式展示
- 显示园区标签（水园/陆园）
- 显示库存状态（充足/预警/缺货）
- 显示有效期状态（正常/近效期/已过期）

✅ **导出功能**
- 导出Excel报表
- 导出PDF报表
- 按当前筛选条件导出

✅ **快捷操作**
- 点击药材卡片查看详情
- 点击"查看批次"跳转到园区库存页面
