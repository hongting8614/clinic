## 🏗️ 技术架构

### 前端（pages-sub/in/add.vue）

```
扫码流程：
用户点击扫码按钮
    ↓
调用 uni.scanCode() 微信官方API
    ↓
清洗条形码（去除空格、换行符）
    ↓
调用云函数 drugBarcodeQuery
    ↓
处理返回结果
    ↓
添加到入库列表 / 提示创建档案
```

**关键代码：**
```javascript
async scanBarcode() {
  // 1. 调用微信扫码API
  const scanRes = await uni.scanCode({
    scanType: ['barCode', 'qrCode', 'datamatrix', 'pdf417'],
    onlyFromCamera: false,
    autoDecrypt: true
  })
  
  // 2. 清洗条形码
  let cleanBarcode = scanRes.result
    .trim()
    .replace(/\s/g, '')
    .replace(/[\r\n]/g, '')
  
  // 3. 查询药材
  await this.queryDrugByBarcode(cleanBarcode)
}
```

### 后端（cloudfunctions/drugBarcodeQuery/index.js）

```
三级查询策略：
1. 查询本地药材档案（drugs集合）
   - 兼容 barcode 和 barCode 两种字段名
   - 支持模糊匹配
   ↓
2. 查询缓存数据库（drug_barcode_cache集合）
   - 30天有效期
   - 自动更新查询次数
   ↓
3. 查询条形码映射表（barcode_mapping集合）
   - 手动录入的映射关系
   - 包含完整药材信息
   ↓
返回结果 / 提示未找到
```

**关键特性：**
- ✅ 兼容多种字段名（barcode / barCode）
- ✅ 详细的日志输出（便于调试）
- ✅ 智能错误处理
- ✅ 性能优化（缓存机制）

## 🎯 已解决的问题

### 问题1：字段名不一致 ⭐⭐⭐⭐⭐

**问题描述：** 数据库中存在 `barcode` 和 `barCode` 两种字段名

**解决方案：**
```javascript
// 云函数兼容两种字段名
const _ = db.command
const res = await db.collection('drugs')
  .where(_.or([
    { barcode: barcode },
    { barCode: barcode }
  ]))
  .get()
```

### 问题2：条形码格式不一致 ⭐⭐⭐⭐

**问题描述：** 扫码结果可能包含空格、换行符

**解决方案：**
```javascript
// 前端清洗条形码
let cleanBarcode = scanRes.result
  .trim()                    // 去除首尾空格
  .replace(/\s/g, '')        // 去除所有空格
  .replace(/[\r\n]/g, '')    // 去除换行符
```

### 问题3：错误提示不够详细 ⭐⭐⭐⭐

**问题描述：** 用户不知道为什么扫码失败

**解决方案：**
- ✅ 区分不同错误类型（云函数未部署、网络超时、权限不足等）
- ✅ 提供详细的错误信息和解决建议
- ✅ 引导用户查看控制台日志

**问题描述：** 未录入的药材扫码后无法快速创建

### 3. 条形码清洗脚本

```javascript
// scripts/清洗条形码.js
async function cleanBarcodes() {
  const db = cloud.database()
  
  const res = await db.collection('drugs')
    .where({ barcode: db.command.exists(true) })
    .get()
  
  for (const drug of res.data) {
    const cleanedBarcode = drug.barcode
      .trim()
      .replace(/\s/g, '')
      .replace(/[\r\n]/g, '')
    
    if (cleanedBarcode !== drug.barcode) {
      await db.collection('drugs').doc(drug._id).update({
        data: { barcode: cleanedBarcode }
      })
    }
  }
}
```
