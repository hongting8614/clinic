# 扫码功能问题排查与修复方案

## 🔍 问题描述

**现象：** 真机上扫码提示"扫码失败，请重试"

**影响范围：** 入库单添加药材时的扫码功能

---

## 🛠️ 已实施的修复

### 1. 优化扫码参数

**修改前：**
```javascript
scanType: ['barCode', 'qrCode', 'datamatrix', 'pdf417'],
onlyFromCamera: false  // 可以从相册选择
```

**修改后：**
```javascript
scanType: ['barCode', 'qrCode'],  // 简化为常用类型
onlyFromCamera: true  // 只从相机扫码，提高成功率
```

**原因：**
- 减少扫码类型，提高识别速度
- 只使用相机扫码，避免相册图片识别失败

---

### 2. 增强条形码清洗

**修改前：**
```javascript
let cleanBarcode = scanRes.result
    .trim()
    .replace(/\s/g, '')
    .replace(/[\r\n]/g, '')
```

**修改后：**
```javascript
let cleanBarcode = String(scanRes.result)  // 确保是字符串
    .trim()
    .replace(/\s/g, '')
    .replace(/[\r\n]/g, '')
    .replace(/[^\w\-]/g, '')  // 只保留字母数字和连字符
```

**原因：**
- 确保结果是字符串类型
- 移除所有特殊字符，只保留有效字符

---

### 3. 降低条形码长度要求

**修改前：**
```javascript
if (!cleanBarcode || cleanBarcode.length < 8) {
    // 拒绝
}
```

**修改后：**
```javascript
if (!cleanBarcode || cleanBarcode.length < 6) {
    // 拒绝
}
```

**原因：**
- 部分药品条形码可能较短
- 降低门槛，提高兼容性

---

### 4. 增强错误处理

**新增功能：**

#### 权限检查
```javascript
if (err.errMsg && err.errMsg.includes('authorize')) {
    uni.showModal({
        title: '需要相机权限',
        content: '请在手机设置中允许小程序使用相机权限',
        confirmText: '去设置',
        success: (res) => {
            if (res.confirm) {
                uni.openSetting()
            }
        }
    })
}
```

#### 用户取消处理
```javascript
if (err.errMsg && err.errMsg.includes('cancel')) {
    console.log('用户取消扫码')
    return  // 静默处理，不提示错误
}
```

## 🔧 可能的问题原因

### 1. 相机权限未授权

**症状：** 点击扫码按钮无反应或直接失败

**解决方案：**
```
1. 打开手机"设置"
2. 找到"微信"应用
3. 点击"权限管理"
4. 开启"相机"权限
```

---

### 2. 光线不足

**症状：** 扫码界面打开但无法识别

**解决方案：**
- 在光线充足的环境下扫码
- 打开手机闪光灯
- 调整条形码与相机的距离（10-20cm）

---

### 3. 条形码模糊或损坏

**症状：** 扫码后提示"条形码格式错误"

**解决方案：**
- 确保条形码清晰可见
- 擦拭条形码表面
- 如果条形码损坏，使用手动输入

---

### 4. 网络问题

**症状：** 扫码成功但查询失败

**解决方案：**
- 检查网络连接
- 切换到Wi-Fi或4G网络
- 重试扫码

---

### 5. 云函数未部署

**症状：** 扫码后提示"云函数未部署"

**解决方案：**
```
1. 打开微信开发者工具
2. 找到 cloudfunctions/drugBarcodeQuery
3. 右键点击 → "上传并部署：云端安装依赖"
4. 等待部署完成
```

### 常见问题FAQ

#### Q1: 扫码按钮在哪里？
**A:** 在入库单页面顶部的搜索框右侧，有一个蓝色的圆形按钮（带扫描框图标）。

#### Q2: 为什么扫码后没反应？
**A:** 可能原因：
1. 相机权限未授权 → 去设置中开启
2. 光线太暗 → 打开闪光灯
3. 条形码模糊 → 擦拭后重试
4. 网络问题 → 检查网络连接

#### Q3: 扫码识别不出来怎么办？
**A:** 可以使用手动输入：
1. 在搜索框输入药品名称
2. 如果找不到，点击"手动新建"
3. 填写药品信息并保存

#### Q4: 扫码后提示"首次识别此条形码"？
**A:** 这是正常的，说明系统中还没有这个药品的信息：
1. 点击"手动新建"
2. 填写药品名称、规格、单位等信息
3. 系统会自动保存条形码映射
4. 下次扫码就能直接识别了

#### Q5: 可以扫描二维码吗？
**A:** 可以，系统支持：
- ✅ 一维条形码（常见的商品条形码）
- ✅ 二维码（QR Code）
