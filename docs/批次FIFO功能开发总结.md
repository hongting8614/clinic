## 📊 技术实现

### FIFO算法核心

```javascript
// 1. 按FIFO规则查询批次
const batches = await db.collection('stock')
  .where({
    drugId: drugId,
    location: location || 'drug_storage',
    quantity: _.gt(0)
  })
  .orderBy('expireDate', 'asc')   // 最早有效期优先
  .orderBy('createTime', 'asc')   // 同一天按入库时间
  .get()

// 2. 检查总库存
const totalStock = batches.data.reduce((sum, b) => sum + b.quantity, 0)

// 3. FIFO分配
for (const batch of batches.data) {
  if (remaining <= 0) break
  if (expireDate < now) continue  // 跳过过期
  
  const allocateQty = Math.min(remaining, batch.quantity)
  allocation.push({...})
  remaining -= allocateQty
}
```

## 🎯 使用场景

### 场景1：单批次分配
- **需求**：出库10盒
- **库存**：单批次有50盒
- **结果**：从该批次分配10盒

### 场景2：跨批次分配
- **需求**：出库100盒
- **库存**：批次1有60盒，批次2有50盒
- **结果**：从批次1分配60盒，从批次2分配40盒

### 场景3：近效期提示
- **需求**：出库10盒
- **库存**：批次有效期在90天内
- **结果**：分配成功，标记近效期，提示用户

### 场景4：库存不足
- **需求**：出库100盒
- **库存**：总库存只有80盒
- **结果**：返回失败，提示库存不足
