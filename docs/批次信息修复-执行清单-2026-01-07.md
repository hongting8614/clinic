## ⚠️ 注意事项

### 1. 关于有效期

如果修复后有效期仍然显示"未设置"，说明：
- 数据库中该批次记录本身就没有有效期
- 需要在入库时补录有效期
- 或者手动在数据库中更新该批次记录

**临时解决方案：**
在云开发控制台手动更新：
```javascript
db.collection('stock')
  .doc('d84694f2695d05030ae35fcc020d3504')
  .update({
    data: {
      expireDate: '2025-12-31',
      productionDate: '2024-01-01'
    }
  })
```

### 2. 关于单位

如果修复后单位仍然显示"盒"，需要检查：
1. 药品档案中的 `minUnit` 字段是否正确
2. 前端模板是否使用了正确的字段

**检查药品档案：**
```javascript
db.collection('drugs')
  .doc('4289fa81692e7e1005ea88de5a1be4d0')
  .get()
  .then(res => {
    console.log('药品档案:', {
      name: res.data.name,
      minUnit: res.data.minUnit,
      packUnit: res.data.packUnit,
      unit: res.data.unit
    })
  })
```

### 3. 长期解决方案

**修复入库流程：**
1. 确保入库时必须填写有效期和生产日期
2. 确保保存 minUnit 和 packUnit
3. 添加表单验证，防止遗漏

**数据修复：**
1. 对现有批次数据进行补录
2. 从入库单中恢复有效期信息
3. 从药品档案中补充单位信息
