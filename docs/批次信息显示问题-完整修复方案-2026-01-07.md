# 🔧 批次信息显示问题 - 完整修复方案

**问题时间：** 2026年1月7日  
**问题根源：** 数据库中批次记录缺少关键字段

---

## 📊 问题确认

### 控制台输出的批次数据
```javascript
批次1: {
  _id: "d84694f2695d05030ae35fcc020d3504",
  batch: "2478877666",
  quantity: 40,
  unit: "片",           // ✅ 有单位
  minUnit: undefined,   // ❌ 缺失
  packUnit: undefined,  // ❌ 缺失
  expireDate: undefined,// ❌ 缺失
  productionDate: undefined, // ❌ 缺失
  location: "land_park",
  drugId: "4289fa81692e7e1005ea88de5a1be4d0",
  drugName: "硝酸甘油片"
}
```

### 问题分析

**根本原因：** 数据库 `stock` 集合中的批次记录本身就缺少这些字段！

这说明：
1. 入库时没有正确保存有效期和生产日期
2. 入库时没有保存 minUnit 和 packUnit
3. 只保存了基本的 unit 字段

### 方案2：从药品档案补充字段（治标）⭐⭐⭐⭐

**在查询批次时，从药品档案中补充缺失的字段**

**位置：** `cloudfunctions/stockManage/index.js` 的 `getBatchList` 方法

**修改代码：**

```javascript
async function getBatchList(data) {
  const { drugId, location, enableFIFO = true } = data
  
  console.log('📊 [云函数] getBatchList 调试:')
  console.log('  - drugId:', drugId)
  console.log('  - location:', location)
  
  if (!drugId) {
    return {
      success: false,
      message: '药材ID不能为空'
    }
  }
  
  // 1. 查询批次列表
  let where = {
    drugId: drugId,
    quantity: _.gt(0)
  }
  
  if (location) {
    where.location = location
  }
  
  let query = db.collection('stock').where(where)
  
  if (enableFIFO) {
    query = query.orderBy('expireDate', 'asc')
  } else {
    query = query.orderBy('createTime', 'desc')
  }
  
  const result = await query.get()
  
  console.log('  - 查询结果数量:', result.data.length)
  
  if (result.data.length === 0) {
    return {
      success: true,
      data: []
    }
  }
  
  // ⭐ 2. 从药品档案获取完整信息
  let drugInfo = null
  try {
    const drugRes = await db.collection('drugs')
      .doc(drugId)
      .get()
    
    if (drugRes.data) {
      drugInfo = drugRes.data
      console.log('  ✅ 从药品档案获取到信息:', {
        name: drugInfo.name,
        minUnit: drugInfo.minUnit,
        packUnit: drugInfo.packUnit,
        conversionRate: drugInfo.conversionRate
      })
    }
  } catch (err) {
    console.warn('  ⚠️ 获取药品档案失败:', err.message)
  }
  
  // 3. 补充批次数据
  const now = new Date()
  const threeMonthsLater = new Date(now.getTime() + 90 * 24 * 60 * 60 * 1000)
  
  const batchList = result.data.map(batch => {
    // ⭐ 从药品档案补充缺失的字段
    const minUnit = batch.minUnit || drugInfo?.minUnit || batch.unit || '片'
    const packUnit = batch.packUnit || drugInfo?.packUnit || batch.unit || '盒'
    const conversionRate = batch.conversionRate || drugInfo?.conversionRate || 1
    
    // 处理有效期
    let expireDate = batch.expireDate
    let isNearExpiry = false
    let daysToExpiry = 0
    
    if (expireDate) {
      const expireDateObj = new Date(expireDate)
      isNearExpiry = expireDateObj <= threeMonthsLater
      daysToExpiry = Math.floor((expireDateObj - now) / (1000 * 60 * 60 * 24))
    }
    
    const quantity = Number(batch.quantity) || 0
    
    return {
      _id: batch._id,
      batch: batch.batch,
      quantity: quantity,
      unit: batch.unit || minUnit,
      minUnit: minUnit,              // ⭐ 补充最小单位
      packUnit: packUnit,            // ⭐ 补充包装单位
      conversionRate: conversionRate,// ⭐ 补充换算比例
      expireDate: expireDate || '',  // ⭐ 有效期
      productionDate: batch.productionDate || '', // ⭐ 生产日期
      price: batch.price || 0,
      location: batch.location,
      drugId: batch.drugId,
      drugName: batch.drugName,
      specification: batch.specification,
      isNearExpiry: isNearExpiry,
      daysToExpiry: daysToExpiry
    }
  })
  
  console.log('  ✅ 返回批次列表:', batchList.length, '个')
  batchList.forEach((batch, i) => {
    console.log(`    批次${i + 1}:`, {
      batch: batch.batch,
      quantity: batch.quantity,
      unit: batch.unit,
      minUnit: batch.minUnit,
      packUnit: batch.packUnit,
      expireDate: batch.expireDate,
      productionDate: batch.productionDate
    })
  })
  
  return {
    success: true,
    data: batchList
  }
}
```

**临时方案：** 显示"未设置"
```vue

```

**长期方案：** 
1. 修复入库流程，确保入库时必须填写有效期

**问题：** 为什么显示"40 盒"而不是"40 片"？

**可能原因：**
1. 模板中使用了 `packUnit` 而不是 `minUnit`
