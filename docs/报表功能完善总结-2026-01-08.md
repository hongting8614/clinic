#### 📦 库存报表 (stock.vue)
**功能**：
- ✅ 当前库存状态查询
- ✅ 库存预警提示
- ✅ 效期风险管理
- ✅ Excel/PDF导出

**筛选条件**：
- 园区筛选（总库存/有库存/水园/陆园）
- 药材筛选（名称/规格/拼音）
- 状态筛选（全部/充足/预警/缺货/近效期/已过期）

**统计数据**：
- 药材种类数
- 总库存数量
- 库存预警药材数
- 近效期/已过期批次数

**库存状态定义**：
- 充足：库存 > 最低库存
- 预警：0 < 库存 ≤ 最低库存
- 缺货：库存 = 0

**效期状态定义**：
- 正常：剩余天数 > 90天
- 近效期：0 < 剩余天数 ≤ 90天
- 已过期：剩余天数 < 0

**导出格式**：
- Excel (.xlsx)
- PDF (.pdf)

## 四、导出功能说明

### 4.1 Excel导出

**技术实现**：
- 云函数生成Excel文件
- 支持多工作表（Sheet）
- 自动列宽调整
- 表头样式美化

**文件结构**：
- 统计信息区域
- 数据表格
- 制表人、制表时间

**文件命名**：
```
{报表类型}_report_{日期时间戳}.xlsx

示例：
- inbound_report_20260108_143025.xlsx
- clinic_report_20260108_143025.xlsx
```

---

### 4.2 PDF导出

**技术实现**：
- 云函数生成PDF文件
- 支持中文字体
- 自动分页
- 页眉页脚

**文件结构**：
- 标题：报表名称
- 统计信息区域
- 数据表格
- 页脚：制表人、制表时间、页码

**文件命名**：
```
{报表类型}_report_{日期时间戳}.pdf

示例：
- outbound_report_20260108_143025.pdf
- stock_report_20260108_143025.pdf
```

---

### 4.3 文件保存位置

**微信小程序**：
- 保存路径：`微信 > 我 > 服务 > 小程序 > 我的文件`
- 可直接打开、分享或导出到其他应用

**操作步骤**：
1. 点击"导出Excel"或"导出PDF"
2. 等待生成完成
3. 自动打开文件或显示保存提示
4. 在微信"我的文件"中查看

## 五、使用场景

### 5.1 日常统计

**每日统计**：
- 使用"门诊日报"生成当日接诊统计
- 导出模板CSV用于上报

**每周统计**：
- 使用"门诊登记表"，筛选本周数据
- 导出Excel进行周报汇总

**每月统计**：
- 使用"入库报表"和"出库报表"，筛选本月数据
- 导出PDF存档

---

### 5.2 库存管理

**日常盘点**：
- 使用"库存报表"查看当前库存
- 筛选"有库存"查看实际在库药品

**效期管理**：
- 使用"库存报表"，筛选"近效期"
- 导出Excel制定处理计划

**补货管理**：
- 使用"库存报表"，筛选"预警"或"缺货"
- 导出Excel制定采购计划

---

### 5.3 查询追溯

**患者历史查询**：
- 使用"门诊病历查询"，输入患者姓名
- 查看历史就诊记录

**处方追溯**：
- 使用"处方查询"，输入患者姓名或药品名称
- 验证电子签名确保数据完整性

**药品流向追溯**：
- 使用"入库报表"查询药品来源
- 使用"出库报表"查询药品去向
- 通过批号关联完整追溯链
