# 北京欢乐谷医务室报表格式说明文档

## 文档概述

本文档详细说明了医务室管理系统中所有报表的数据格式、字段定义、导出功能和使用场景。

## 一、门诊相关报表

### 1.4 日报（daily.vue）

**报表名称**：门诊日报

**用途**：生成每日门诊接诊统计报告

**生成方式**：
- 自动根据当天门诊登记数据生成
- 支持手动编辑日报内容

**统计数据**：

| 统计项 | 说明 | 示例 |
|--------|------|------|
| total | 总接诊人数 | 25 |
| visitorTotal | 游客接诊人数 | 18 |
| employeeTotal | 员工接诊人数 | 7 |
| outcallTotal | 出诊次数 | 3 |

**日报文本格式**：
```
2024年1月8日北京欢乐谷医务室（陆园）当日接诊共计25人。
游客18人：擦伤5人（欢乐时光3人，太阳神车2人），扭伤3人，感冒2人，其他8人。
员工7人：感冒3人，头痛2人，腹泻1人，其他1人。
出诊3次：欢乐时光2次，太阳神车1次。
```

**导出模板（CSV格式）**：

游客模板列：
- 日期/受伤类型
- 扭伤、擦伤、地点（擦伤）
- 烫伤、磕伤、冻伤
- 腹泻、头晕、头痛
- 感冒、脱臼、骨折、地点（骨折）
- 过敏、痛经、测血压
- 其他、合计
- 接诊医生、备注

员工模板列：同上

**导出格式**：
- 复制文本（可粘贴到Excel）
- CSV文件
- 模板CSV（游客/员工分开）

### 2.3 库存报表（stock.vue）

**报表名称**：库存报表

**用途**：查看当前库存状态、预警信息和效期风险

**筛选条件**：
- 园区筛选（总库存 / 有库存 / 水园 / 陆园）
- 药材筛选（支持药材名称/规格/拼音模糊查询）
- 状态筛选（全部 / 充足 / 预警 / 缺货 / 近效期 / 已过期）

**统计数据**：

| 统计项 | 说明 | 示例 |
|--------|------|------|
| totalDrugs | 药材种类数 | 45 |
| totalQuantity | 总库存数量 | 2,350 |
| warningCount | 库存预警药材数 | 8 |
| expiryRiskCount | 近效期/已过期批次数 | 3 |

**库存明细字段**：

| 字段名 | 字段说明 | 数据类型 | 示例 |
|--------|----------|----------|------|
| drugName | 药材名称 | String | 布洛芬缓释胶囊 |
| specification | 规格 | String | 0.3g*20粒 |
| unit | 单位 | String | 盒 |
| quantity | 库存数量 | Number | 15 |
| location | 园区 | String | land_park / water_park |
| locationName | 园区名称 | String | 陆园 / 水园 |
| batch | 批号 | String | 20231201 |
| expireDate | 有效期 | Date | 2025-12-01 |
| expireDays | 剩余天数 | Number | 365 |
| expireDaysText | 效期提示 | String | 剩余365天 / 已过期30天 |
| statusTag | 库存状态标签 | String | normal / warning / empty |
| statusText | 库存状态文本 | String | 充足 / 预警 / 缺货 |
| expireTag | 效期状态标签 | String | normal / near / expired |

**库存状态定义**：
- **充足**：库存数量 > 最低库存
- **预警**：0 < 库存数量 ≤ 最低库存
- **缺货**：库存数量 = 0

**效期状态定义**：
- **正常**：剩余天数 > 90天
- **近效期**：0 < 剩余天数 ≤ 90天
- **已过期**：剩余天数 < 0

**导出格式**：
- Excel (.xlsx)
- PDF (.pdf)

**导出文件命名规则**：
- Excel: `stock_report_YYYYMMDD_HHMMSS.xlsx`
- PDF: `stock_report_YYYYMMDD_HHMMSS.pdf`

## 三、报表导出功能说明

### 3.1 Excel导出

**技术实现**：
- 使用云函数生成Excel文件
- 支持多工作表（Sheet）
- 自动列宽调整
- 表头样式美化

**Excel文件结构**：

**入库/出库报表**：
- Sheet1: 汇总数据（如选择汇总模式）
- Sheet2: 明细数据（如选择明细模式）
- 包含统计信息、制表人、制表时间

**库存报表**：
- Sheet1: 库存明细
- 包含统计信息、制表人、制表时间

**门诊报表**：
- Sheet1: 门诊记录明细
- 包含统计信息、制表人、制表时间

### 3.2 PDF导出

**技术实现**：
- 使用云函数生成PDF文件
- 支持中文字体
- 自动分页
- 页眉页脚

**PDF文件结构**：
- 标题：报表名称
- 统计信息区域
- 数据表格
- 页脚：制表人、制表时间、页码

### 3.3 文件保存位置

**微信小程序**：
- 文件保存路径：`微信 > 我 > 服务 > 小程序 > 我的文件`
- 文件可直接打开、分享或导出到其他应用

**文件命名规范**：
```
{报表类型}_{日期时间戳}.{扩展名}

示例：
- inbound_report_20240108_143025.xlsx
- outbound_report_20240108_143025.pdf
- stock_report_20240108_143025.xlsx
- clinic_report_20240108_143025.xlsx
```

## 五、报表使用场景

### 5.1 日常统计场景

**每日统计**：
- 使用"日报"功能生成当日接诊统计
- 导出模板CSV用于上报

**每周统计**：
- 使用"门诊登记表"，筛选本周数据
- 导出Excel进行周报汇总

**每月统计**：
- 使用"入库报表"和"出库报表"，筛选本月数据
- 导出PDF存档

### 5.2 库存管理场景

**日常盘点**：
- 使用"库存报表"查看当前库存
- 筛选"有库存"查看实际在库药品

**效期管理**：
- 使用"库存报表"，筛选"近效期"
- 导出Excel制定处理计划

**补货管理**：
- 使用"库存报表"，筛选"预警"或"缺货"
- 导出Excel制定采购计划

### 5.3 查询追溯场景

**患者历史查询**：
- 使用"门诊病历查询"，输入患者姓名
- 查看历史就诊记录

**处方追溯**：
- 使用"处方查询"，输入患者姓名或药品名称
- 验证电子签名确保数据完整性

**药品流向追溯**：
- 使用"入库报表"查询药品来源
- 使用"出库报表"查询药品去向
- 通过批号关联完整追溯链

## 六、注意事项

### 6.1 数据准确性

1. **时间范围**：确保选择正确的时间范围，避免遗漏数据
2. **园区选择**：注意区分陆园、水园和全部园区
3. **草稿数据**：根据需要选择是否包含草稿数据

### 6.2 导出文件管理

1. **文件命名**：导出文件自动包含时间戳，便于区分
2. **文件保存**：及时将重要报表导出到电脑或云盘备份
3. **文件分享**：可通过微信直接分享导出的Excel或PDF文件

### 6.3 数据安全

1. **电子签名**：处方和病历支持电子签名验证，确保数据完整性
2. **权限控制**：不同角色用户看到的数据范围可能不同
3. **数据备份**：定期导出重要报表进行备份

## 七、常见问题

### Q1: 为什么导出的Excel打不开？

**A**: 请确保使用Excel 2007或更高版本，或使用WPS Office打开。

### Q2: 如何将报表分享给其他人？

**A**: 导出Excel或PDF后，在微信"我的文件"中找到文件，点击分享即可。

### Q3: 日报中的"其他"项目包含哪些？

**A**: "其他"项目包含所有未在固定疾病清单中的诊断，具体内容会在备注栏详细列出。

### Q4: 库存报表中的"有库存"和"总库存"有什么区别？

**A**: "总库存"显示所有药品（包括数量为0的），"有库存"只显示数量大于0的药品。

### Q5: 如何验证处方的电子签名？

**A**: 在处方查询页面，点击每条记录底部的"校验签名"按钮即可验证。

**表格名称**：北京欢乐谷医务室门诊登记表

**用途**：日常门诊接诊记录，用于手工登记或作为电子系统的备份

**表格规格**：A4横向（297mm × 210mm）

**表格结构**：

### 9.2 字段填写说明

#### 基本信息字段

**序号**：
- 填写方式：按当日接诊顺序填写，从1开始
- 示例：1, 2, 3...

**就诊时间**：
- 填写方式：HH:MM格式
- 示例：09:30, 14:15

**姓名**：
- 填写方式：患者真实姓名，如患者不愿提供可填写"游客"
- 示例：张三、李四、游客

**性别**：
- 填写方式：男/女
- 示例：男、女

**年龄**：
- 填写方式：实际年龄数字，儿童可标注"岁"或"月"
- 示例：28、5岁、8个月

**身份**：
- 填写方式：游客/员工
- 示例：游客、员工

#### 诊疗信息字段

**主诉**：
- 填写方式：简要描述患者主要症状或不适
- 示例：头痛头晕、擦伤、腹痛、发热

**初步诊断**：
- 填写方式：根据症状给出的初步诊断结果
- 示例：感冒、外伤、急性胃肠炎、高血压

**处置**：
- 填写方式：记录处置措施和用药情况，药品名称 + 数量 + 单位，多种药品用"；"分隔
- 示例：
  - 布洛芬缓释胶囊 2粒
  - 阿莫西林胶囊 6粒；感冒灵颗粒 2袋
  - 碘伏消毒、创可贴 2片

**医生**：
- 填写方式：接诊医生姓名或手写签名
- 说明：签名表示对本次接诊记录的确认

**备注**：
- 填写方式：记录特殊情况、注意事项、出诊地点等
- 示例：
  - 建议就医、已联系家属、转诊
  - 出诊：欢乐时光、太阳神车、水上乐园入口

### 9.7 门诊登记表使用流程

#### 纸质表格使用流程

1. **准备阶段**
   - 每日开始前准备当日登记表
   - 填写表头的园区和日期信息
   - 检查笔、印章等工具

2. **接诊登记**
   - 按接诊顺序依次填写
   - 确保字迹清晰、信息完整
   - 医生签名确认

3. **日终统计**
   - 填写表尾统计信息
   - 值班医生和记录人签字
   - 归档保存

4. **归档管理**
   - 按日期顺序装订
   - 每月整理归档
   - 保存期限：3年

#### 电子表格使用流程

1. **系统登记**
   - 打开小程序门诊登记功能
   - 填写患者基本信息
   - 录入诊疗信息
   - 添加用药记录
   - 保存并签名

2. **数据查询**
   - 进入门诊查询功能
   - 设置筛选条件
   - 查看登记记录
   - 导出报表

3. **数据导出**
   - 选择导出格式（Excel/PDF）
   - 设置导出范围
   - 生成并下载文件
   - 分享或存档

### 9.8 门诊登记表质量控制

#### 数据完整性检查

**必填项检查**：
- ✓ 就诊时间
- ✓ 姓名
- ✓ 性别
- ✓ 年龄
- ✓ 身份
- ✓ 就诊类型
- ✓ 主诉
- ✓ 初步诊断
- ✓ 医生签名

**逻辑性检查**：
- 出诊类型必须填写出诊地点
- 年龄范围合理性（0-150岁）
- 就诊时间不能晚于当前时间
- 用药信息与诊断相关性

#### 数据准确性检查

**定期抽查**：
- 每周抽查10%的登记记录
- 核对纸质记录与电子记录一致性
- 检查签名真实性

**异常数据处理**：
- 发现错误及时更正
- 重大错误需要说明原因
- 保留修改痕迹

### 9.9 常见问题处理

**Q1: 患者不愿提供真实姓名怎么办？**
A: 可填写"游客"或"患者"，但需在备注栏记录特征信息（如：穿红色T恤的男性游客）

**Q2: 一次接诊使用多种药品如何记录？**
A: 用分号"；"分隔，如：布洛芬缓释胶囊 2粒；感冒灵颗粒 2袋

**Q3: 出诊时如何快速登记？**
A: 可先简要记录关键信息，返回医务室后补充完整

**Q4: 登记表填写错误如何修改？**
A: 纸质表格：单线划掉错误内容，在旁边写正确内容并签名
   电子系统：直接修改，系统会保留修改记录

**Q5: 登记表需要保存多久？**
A: 纸质表格保存3年，电子记录永久保存
