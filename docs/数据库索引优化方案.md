# 数据库索引优化方案

## 📊 当前问题

根据控制台提示，以下查询缺少索引：

```javascript
db.collection('drugs')
  .where({})
  .orderBy('createTime', 'desc')
  .get()
```

## 🔧 优化方案

### 1. 为 drugs 集合创建索引

**索引配置：**
```json
{
  "collection": "drugs",
  "indexes": [
    {
      "name": "createTime_desc",
      "keys": [
        {
          "field": "createTime",
          "type": -1
        }
      ]
    }
  ]
}
```

**创建方式：**

#### 方式1：通过控制台快速创建（推荐）

点击控制台中的快速创建链接：
```
cloud://createindex?env=cloud1-3gv7spppf7d2d0f4&collection=drugs&from=console&s=%5B%7B%22field%22%3A%22createTime%22%2C%22type%22%3A-1%7D%5D
```

#### 方式2：手动创建

1. 打开微信开发者工具
2. 进入"云开发"控制台
3. 选择"数据库" → "drugs"集合
4. 点击"索引管理"
5. 添加索引：
   - 字段名：`createTime`
   - 排序：降序（-1）
   - 索引名：`createTime_desc`

### 2. 其他建议的索引

根据库存模块的查询需求，建议创建以下索引：

#### stock 集合（库存表）

```json
{
  "collection": "stock",
  "indexes": [
    {
      "name": "location_drugName",
      "keys": [
        {"field": "location", "type": 1},
        {"field": "drugName", "type": 1}
      ]
    },
    {
      "name": "location_quantity",
      "keys": [
        {"field": "location", "type": 1},
        {"field": "quantity", "type": -1}
      ]
    },
    {
      "name": "expireDate_asc",
      "keys": [
        {"field": "expireDate", "type": 1}
      ]
    }
  ]
}
```

**用途：**
- `location_drugName`：按园区查询药材
- `location_quantity`：按园区查询库存数量
- `expireDate_asc`：查询近效期药材

#### clinic_records 集合（门诊记录）

```json
{
  "collection": "clinic_records",
  "indexes": [
    {
      "name": "location_visitDateTime",
      "keys": [
        {"field": "location", "type": 1},
        {"field": "visitDateTime", "type": -1}
      ]
    },
    {
      "name": "createTime_desc",
      "keys": [
        {"field": "createTime", "type": -1}
      ]
    }
  ]
}
```

**用途：**
- `location_visitDateTime`：按园区和时间查询门诊记录
- `createTime_desc`：按创建时间排序

## 💡 索引使用建议

### 1. 复合索引的顺序

复合索引的字段顺序很重要：

```javascript
// ✅ 正确：先筛选再排序
{location: 1, createTime: -1}

// ❌ 错误：先排序再筛选
{createTime: -1, location: 1}
```

**规则：**
- 等值查询字段放前面
- 范围查询字段放中间
- 排序字段放最后

### 2. 索引覆盖查询

尽量让查询只使用索引字段：

```javascript
// ✅ 索引覆盖查询（快）
db.collection('stock')
  .field({drugName: true, quantity: true, location: true})
  .where({location: 'water_park'})
  .get()

// ❌ 需要回表查询（慢）
db.collection('stock')
  .where({location: 'water_park'})
  .get()  // 返回所有字段
```

### 3. 避免全表扫描

```javascript
// ❌ 全表扫描
db.collection('drugs').where({}).get()

// ✅ 使用索引
db.collection('drugs')
  .where({})
  .orderBy('createTime', 'desc')
  .limit(20)
  .get()
```

### 2. 索引使用率

定期检查索引使用情况：
- 未使用的索引可以删除
- 频繁使用的查询需要创建索引

### 3. 索引大小

索引会占用存储空间：
- 单个索引 < 集合大小的 10%
- 总索引数 < 64 个
