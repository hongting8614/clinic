# 🔍 门诊开方页面 - 批次信息卡片显示问题分析

**问题时间：** 2026年1月7日  
**问题描述：** 处方下方的批次信息卡片显示不正确

---

## 📊 问题现象（根据截图）

### 显示的内容
```
批次：2478877666
有效期：（空白，没有显示）
剩余库存：40 盒
```

### 问题点
1. ❌ **有效期为空** - 应该显示批次的有效期，但是空白
2. ⚠️ **数量单位是"盒"** - 应该显示最小单位（如"片"），而不是包装单位（"盒"）

---

## 🔍 问题分析

### 可能的原因

#### 1. 批次数据中没有有效期字段

**数据来源：** `selectedBatch` 对象

**可能情况：**
- 批次数据从云函数返回时，`expireDate` 字段为空
- 批次数据结构不完整
- 字段名不匹配（如：`expireDate` vs `expiryDate` vs `expire_date`）

**验证方法：**
```javascript
// 在控制台查看批次数据
console.log('选中的批次数据:', this.selectedBatch)
console.log('有效期字段:', this.selectedBatch.expireDate)
```

#### 2. 模板中使用了错误的字段名

**可能的代码：**
```vue
<!-- 错误的字段名 -->
<text>有效期：{{ selectedBatch.expiryDate }}</text>

<!-- 正确的字段名应该是 -->
<text>有效期：{{ selectedBatch.expireDate }}</text>
```

#### 3. 数量单位使用了包装单位

**问题代码：**
```vue
<!-- 使用了 packUnit 或 unit（包装单位） -->
<text>剩余库存：{{ selectedBatch.quantity }} {{ selectedBatch.unit }}</text>

<!-- 应该使用 minUnit（最小单位） -->
<text>剩余库存：{{ selectedBatch.quantity }} {{ selectedBatch.minUnit || selectedBatch.unit }}</text>
```

## 🔧 修复方案

### 方案1：检查批次数据来源

**位置：** `pages-sub/clinic/add.vue` 中的 `loadBatches` 方法

**检查点：**
```javascript
async loadBatches() {
  const res = await wx.cloud.callFunction({
    name: 'stockManage',
    data: {
      action: 'getBatchList',
      data: {
        drugId: this.selectedDrug.id,
        location: this.form.location
      }
    }
  })
  
  if (res.result.success && res.result.data.length > 0) {
    const batches = res.result.data
    
    // 🔍 检查批次数据结构
    console.log('批次数据详情:')
    batches.forEach((b, i) => {
      console.log(`批次${i+1}:`, {
        batch: b.batch,
        quantity: b.quantity,
        unit: b.unit,
        minUnit: b.minUnit,
        packUnit: b.packUnit,
        expireDate: b.expireDate,        // ⭐ 检查这个字段
        productionDate: b.productionDate,
        location: b.location
      })
    })
    
    this.selectedBatch = batches[0]
  }
}
```

```javascript
// cloudfunctions/stockManage/index.js
async function getBatchList(data) {
  // ... 查询代码 ...
  
  const batchList = result.data.map(batch => {
    return {
      _id: batch._id,
      batch: batch.batch,
      quantity: batch.quantity,
      unit: batch.unit,
      minUnit: batch.minUnit || batch.unit,  // ⭐ 确保有最小单位
      packUnit: batch.packUnit || batch.unit,
      expireDate: batch.expireDate,          // ⭐ 确保有有效期
      productionDate: batch.productionDate,
      location: batch.location,
      drugId: batch.drugId,
      drugName: batch.drugName
    }
  })
  
  return {
    success: true,
    data: batchList
  }
}
```
