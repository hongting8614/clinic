# 🔧 门诊开方页面批次信息显示问题修复

**问题时间：** 2026年1月7日  
**问题描述：** 门诊开方页面不显示批次号、有效期，数量单位不是最小单位

---

## 📊 问题分析

### 1. 批次信息被隐藏

**位置：** `pages-sub/clinic/add.vue` 第554行和第581行

**问题代码：**
```vue
<!-- ❌ 批次分配信息被强制隐藏 -->
<view v-if="false" class="batch-allocation-info">
  <view class="batch-allocation-header">
    <text class="batch-label">📦 批次分配：</text>
    <text class="batch-count">{{ item.batchCount }}个批次</text>
  </view>
  <!-- ... 批次详情 ... -->
</view>

<!-- ❌ 单批次信息也被强制隐藏 -->
<view v-if="false" class="batch-single-info">
  <text class="batch-label">批次：</text>
  <text class="batch-value">{{ item.batchNumber }}</text>
</view>
```

**原因：** 在提交 `42b2d31` 中，为了"隐藏门诊开方处方中的批次信息显示"，将条件改为了 `v-if="false"`

### 2. 数量单位问题

**可能原因：**
- 使用了 `packUnit`（包装单位，如"盒"）而不是 `minUnit`（最小单位，如"片"）
- 批次数据中的 `unit` 字段可能是包装单位

---

## 🔧 修复方案

### 方案1：恢复批次信息显示（推荐）⭐⭐⭐⭐⭐

**修改文件：** `pages-sub/clinic/add.vue`

**修改内容：**

```vue
<!-- 修复：恢复批次分配信息显示 -->
<view v-if="item.batchAllocation && item.batchAllocation.length > 0" class="batch-allocation-info">
  <view class="batch-allocation-header">
    <text class="batch-label">📦 批次分配：</text>
    <text class="batch-count">{{ item.batchCount }}个批次</text>
  </view>
  
  <view class="batch-list">
    <view 
      v-for="(batch, bIdx) in item.batchAllocation" 
      :key="bIdx"
      class="batch-item"
    >
      <view class="batch-row">
        <text class="batch-label">批次：</text>
        <text class="batch-value">{{ batch.batch }}</text>
      </view>
      <view class="batch-row">
        <text class="batch-label">数量：</text>
        <text class="batch-value">{{ batch.quantity }} {{ item.minUnit || item.unit }}</text>
      </view>
      <view class="batch-row">
        <text class="batch-label">有效期：</text>
        <text class="batch-value">{{ batch.expireDate }}</text>
      </view>
    </view>
  </view>
</view>

<!-- 修复：恢复单批次信息显示 -->
<view v-else-if="item.batchNumber" class="batch-single-info">
  <view class="batch-row">
    <text class="batch-label">批次：</text>
    <text class="batch-value">{{ item.batchNumber }}</text>
  </view>
  <view class="batch-row" v-if="item.expireDate">
    <text class="batch-label">有效期：</text>
    <text class="batch-value">{{ item.expireDate }}</text>
  </view>
</view>
```

### 方案2：修复数量单位显示

**问题：** 显示的是包装单位（如"盒"）而不是最小单位（如"片"）

**修复：** 确保使用 `minUnit` 字段

```vue
<!-- 修改前 -->
<text class="drug-quantity">{{ item.quantity }} {{ item.unit }}</text>

<!-- 修改后 -->
<text class="drug-quantity">{{ item.quantity }} {{ item.minUnit || item.unit }}</text>
```

### 方案3：在批次选择时确保单位正确

**修改文件：** `pages-sub/clinic/add.vue` 中的批次选择处理方法

```javascript
// 批次选择后的处理
onBatchSelect(batch) {
  console.log('选中批次:', batch)
  
  // 确保使用最小单位
  const minUnit = batch.minUnit || batch.unit || this.selectedDrug.minUnit || this.selectedDrug.unit
  
  // 更新药品信息
  this.selectedDrug.batchNumber = batch.batch
  this.selectedDrug.expireDate = batch.expireDate
  this.selectedDrug.productionDate = batch.productionDate
  this.selectedDrug.unit = minUnit  // 使用最小单位
  this.selectedDrug.minUnit = minUnit
  
  console.log('更新后的单位:', minUnit)
}
```
