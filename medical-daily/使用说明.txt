欢乐谷医务室日报工具 PWA 网页版 v1.2.3

本版优化：
- 疾病名称和发病地点都完全改为自定义下拉列表。
- 移除浏览器原生 datalist，避免手机系统下拉触碰即选。
- 下拉列表可以手指上下滑动浏览。
- 只有轻点候选项且没有明显滑动时，才会选中。
- 滑动浏览候选项时不会误选。
- 选择候选项后下拉列表自动关闭。

适用平台：
- 苹果手机：Safari 浏览器打开网址，可添加到主屏幕。
- 安卓手机：Chrome/Edge/浏览器打开网址，可添加到主屏幕或安装应用。
- Windows 电脑：Chrome/Edge 打开网址，可安装为网页应用。
- Mac 电脑：Safari/Chrome 打开网址。

使用方式：
- 想浏览候选项：按住下拉列表上下滑动。
- 想选择候选项：轻点候选项，不滑动。

GitHub Pages 发布步骤：
1. 登录 GitHub：https://github.com
2. 新建 Public 仓库，建议名称：medical-daily
3. 上传本文件夹内全部文件到仓库根目录。
4. 打开仓库 Settings。
5. 左侧选择 Pages。
6. Source 选择 Deploy from a branch。
7. Branch 选择 main。
8. Folder 选择 /root。
9. 保存后等待生成访问网址。
